# Phase 2 - Logistic Regression

This phase trains and evaluates a logistic regression model for student placement
prediction.

## Run

1. Open `Phase 2 - Logistic Regression.ipynb`.
2. Install the notebook dependencies when prompted.
3. Run all cells from top to bottom.

The notebook displays the evaluation metrics, classification report, confusion
matrix, ROC curve, and the most important logistic-regression coefficients.
It also saves the main evaluation metrics to
`logistic_regression_results.csv`. It does not save a generated model file.
